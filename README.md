### VU Cyber Nexus '26

A cybersecurity training and Capture The Flag (CTF) write-up repository for VU Cyber Nexus '26, developed while training through CyberLab Security Academy.

This repository contains challenge solutions, investigation notes, commands, tools, and lessons learned from our CyberLab Security Academy training. Challenges are organized by category and difficulty level.

## Tools and Topics

### Forensics

File identification, metadata analysis, disk images, deleted-file recovery, file carving, logs, and artifact analysis.

### Binary Exploitation

Memory corruption, buffer overflows, protections, shellcode, return-oriented programming, and debugging.

### Cryptography

Encoding, classical ciphers, hashing, symmetric cryptography, asymmetric cryptography, and cryptanalysis.

### Reverse Engineering

Static analysis, dynamic analysis, disassembly, debugging, decompilation, and binary behavior analysis.

### OSINT

Public-source research, search techniques, metadata, usernames, domains, social-media investigation, and information verification.

### Steganography

Hidden data in images, audio, documents, files, metadata, and alternate data channels.

### Web Exploitation

HTTP, authentication, access control, injection, cross-site scripting, server-side vulnerabilities, and web application analysis.

## Responsible Use

All techniques in this repository are intended for:

- Authorized training environments
- CTF competitions
- Personal laboratories
- Systems where explicit permission has been granted

Do not use these techniques against systems, accounts, networks, or data without authorization.

## Learning Goals

- Build practical cybersecurity skills
- Develop structured investigation habits
- Improve command-line proficiency
- Understand common attack and defense techniques
- Document solutions clearly and reproducibly
- Share knowledge with the cybersecurity community
